# AIDING 学术表达风格

写出一种**把研究对象逐步解释清楚，再使处理方法和判断从解释中自然产生**的行文方式。读者应能顺着文字知道：当前对象是什么，它有什么特性，这些特性带来什么约束，接下来的处理改变了哪一环节，所得结果意味着什么。具体内容服从当前材料，不能搬用语料中的研究事实。

“通用”指这种表达方式能迁移到不同学术主题与写作用途。不要将其稀释为“清晰、正式、有逻辑”，也不要默认扩展为工作通知、资料管理或邮件写法。论文、项目书、学术报告共享表达习惯，研究状态、解释密度和段落任务随用途调整；润色是改写幅度，不是独立文体。

## 读取顺序

1. 每次先读 [行文方式](references/style-fingerprint.md)。首次使用、需要明显重写或用户说“不像”时，再读 [句段拆解](references/paragraph-anatomy.md) 中至少两个相关段落，理解句间关系后写作。
2. 按当前任务只补读相关文体：[论文](references/papers.md)、[科研项目书](references/proposals.md)、[学术报告](references/academic-reports.md)。不自动改动用户给定标题与结构。
3. 需要效果对照时读 [学术试写](references/academic-examples.md)。这些均为构造材料，不是可移植的研究成果。句段拆解同样采用构造例，不依赖原始语料。
4. 共同校准时读 [交互校准](references/calibration.md)。维护与扩充时读 [来源](references/sources.md) 和 [行为评测](references/evaluation.md)。正常写作不依赖原 PDF 所在路径。

## 写作流程

1. **锁定当前事实。** 记录对象、条件、操作、已知关系、结果、判断范围和完成状态。保留数值、公式、符号、引用及其归属。把原材料事实与技能例子分开。
2. **确定本段承担的作用。** 解释概念、提出问题、说明方法、分析结果、论证研究任务或汇报进展，各自选用必要关系。不是每段都写“背景—问题—方法—意义”。
3. **沿对象展开。** 找到贯穿本段的核心名词。让前句得到的对象成为后句解释、处理或评价的对象；当研究对象换了表示形式，明确新旧对象的关系。保留必要的术语重复，不用抽象近义词轮换掩盖对象。
4. **补清已有关系。** 在动作前说明原材料已经提供的必要性；在操作后交代得到什么、用于什么；在结果后给出证据允许的认识。可以显化原文隐含但确定的关系，不能推造机理、定理或实验。
5. **调整节奏。** 紧密相连的条件、动作和后果可用复句展开，重要定义、条件变化或结论另起一句。压缩时先删重复开场和价值修饰，保留使论证成立的桥接句。
6. **按用途落定语气。** 已完成工作直接陈述；拟开展工作保持计划状态；已有支持和新增困难同时交代。学术报告可适度增加解释，论文正文保持信息密度，项目书明确问题与任务的对应。
7. **交付正文。** 常规任务直接给可用文本。用户要求比较时再提供少量同事实版本；默认不附长篇自评，不反复询问文体或风格。

## 风格检验

在心中删去“针对、为此、通过、进一步、从而”等连接词，再看段落是否仍有连续对象、处理关系和逐步展开的解释。若去掉这些词便只剩研究动作的清单，继续整理信息关系；不能以连接词数量判定风格。

检查成稿能否回答本段真正涉及的问题：为什么做这一步；这一步改变了什么；下一步为什么接得上；判断依赖哪些条件。并非每段必须回答全部问题。

用户要求“明显一点”时，加强原有内容的展开、承接和解释，不增加口号、陌生术语、事实或结论力度。用户只要求轻润色时，保留论证顺序和段落结构；原稿已经成熟时允许少改。

## 边界

保留声音，不保留原语料中的笔误、引用异常、冗余和未经支持的绝对判断。现有材料包含共同署名作品，技能表达的是这批团队中文语料的稳定倾向，不能证明某句话由刘东个人执笔，也不宣称与作者无法区分。英文任务只迁移论证组织，不宣称已学得团队英文措辞。

用户最新指示、事实边界、篇幅与格式优先于任何风格规则。
